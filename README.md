# Experiment 2: Git Branching and Merge Conflict Resolution

## Aim
To implement Git branching strategies using GitHub, create branches, merge Pull Requests, and resolve merge conflicts.

## Software Requirements
- GitHub account
- Web browser
- GitHub repository

## Repository Details
- Repository Name: merge-conflict
- Main Branch: main
- Branch 1: Raja
- Branch 2: Pooja

## Experiment Description
A website containing the biography of the Chief Minister of Karnataka is developed using HTML. Two branches, Raja and Pooja, modify the same contact information with different contact numbers.

## Branch Changes
- Raja Branch: 943656789
- Pooja Branch: 9466677788

## Procedure
1. Created the GitHub repository named merge-conflict.
2. Created index.html in the main branch.
3. Created the Raja branch and modified the contact number.
4. Created the Pooja branch from main and modified the same contact line.
5. Created and merged Raja's Pull Request into main.
6. Created Pooja's Pull Request, which produced a merge conflict.
7. Resolved the conflict by retaining Raja's contact number.
8. Merged Pooja's Pull Request and verified the final HTML file.
   
## Final Contact Information
```html
<h2>Contact Information</h2>
<p>Contact No: 943656789</p>
```

## Result
Git branching and Pull Request operations were performed successfully. The merge conflict was identified and resolved manually, and the final changes were merged into the main branch.
